# 数据分析

此处并没有代码的部分，是在网课上学习数据分析和可视化工具的时候做的练习。

## 月度销售数据监控
`月度销售数据监控.xlsx` 对源数据 Sheet 中的数据进行分析和可视化报表制作，包含 Excel 图表的月度销售监控看板。

点击标题处的月份、区域筛选器可以调整图表的的颗粒度
按住ctrl可以多选
